关于 About

它记下什么、做不到什么，以及以什么协议开源。 What it keeps, what it cannot do, and the terms it is shared under.

隐私Privacy

只保存计数：每个键按了几次、点击、滚动手势和鼠标移动距离。不记录输入内容，也不记录按键顺序。所有数据只存在本机，不上传。 Only counts are stored: how many times each key was pressed, clicks, scroll gestures, and how far the mouse moved. It never records what you type or the order of your keys. Everything stays on your machine.

数据在 ~/Library/Application Support/io.github.sparkjokerben.jokbet/（Windows 在 %APPDATA% 下，Linux 在 ~/.local/share/ 下）。 It lives in ~/Library/Application Support/io.github.sparkjokerben.jokbet/ (the same folder under %APPDATA% on Windows and ~/.local/share/ on Linux).

这个网站上的桌宠也一样：它只对你在页面里的操作做反应，纯粹用来演示，什么都不发送。 The pet on this site works the same way: it only reacts to what you do on the page, as a demonstration, and sends nothing.

网站本身用 Cloudflare Web Analytics 统计访问量：不用 Cookie，也不记录你是谁。 The site itself counts visits with Cloudflare Web Analytics, which sets no cookies and does not record who you are.

已知限制Known limits

  • macOS：开了「安全键盘输入」时（终端设置或密码框里），按键对所有程序都不可见，它会戴上眼罩。 macOS: while Secure Keyboard Entry is on (a Terminal setting, or any password field), no app can see the keys — it puts on a blindfold.
  • macOS：没给「输入监控」权限时，它一脸问号，什么也数不到。 macOS: without Input Monitoring permission it is baffled and cannot count a thing.
  • Windows：管理员权限窗口里的输入看不到（除非它也以管理员运行）；它会留在启动时的那个虚拟桌面。 Windows: input going to administrator windows is not seen unless it runs as administrator too, and it stays on the virtual desktop it started on.
  • Linux：只支持 X11，Wayland 下无法工作。 Linux: X11 only; it cannot work under Wayland.
  • 它会待在别的窗口上面，包括全屏应用；遮挡内容时可右键隐藏。 It stays above other windows, fullscreen apps included; hide it from the tray menu when it gets in the way.
