    它会什么What it does

    • 数你按了多少键（按每个键分开记）、左中右键点了多少下、滚了多少次、鼠标走了多少米，全部按天存。 Counts key presses (per key), left, right and middle clicks, scroll gestures and how far the mouse travelled — all kept per day.
    • 头顶一个数字：今天的总次数，或者此刻的手速；来源可以是键盘、鼠标或者两者合计。 One number over its head: today's total, or your speed right now, from the keyboard, the mouse, or both.
    • 你打字，它掏出笔记本一起敲；你点击、滚动，它有反应；光标到哪儿，它的眼睛跟到哪儿。 Type and it gets out a laptop and types along. It reacts to clicks and scrolling, and its eyes follow your cursor.
    • 闲着的时候做什么、单击和双击的反应，都可以自己选（颠球、东张西望、发呆、挥手、比心……）。 What it does when idle, and what a click or double-click gets you, are yours to pick (juggle, look around, breathe, wave, hearts…).
    • 统计窗口里有 7/30/90/365 天的趋势和一张全尺寸键盘热力图，可以导出 CSV。 A stats window with 7/30/90/365-day trends and a full keyboard heatmap, with CSV export.
    • 中英双语，跟随系统语言；到了自己设的里程碑会跳起来庆祝。 Speaks Chinese and English, following your system, and jumps for joy when you hit a milestone you set.

    安装Install

    macOS

    1. 解压后把 Jokbet.app 拖进「应用程序」。Apple 芯片选 aarch64，Intel 选 x64。 Unzip it and move Jokbet.app to Applications. aarch64 for Apple silicon, x64 for Intel.
    2. 首次打开会被拦下，到「系统设置 → 隐私与安全性」点「仍要打开」。 The first launch is blocked: System Settings → Privacy & Security → Open Anyway.
    3. 按提示授予「输入监控」权限。没有它，桌宠会一脸问号，也统计不到任何操作。 Allow Input Monitoring when asked. Without it the pet is confused and counts nothing.

    Windows

    1. 运行下载的安装程序。 Run the installer you downloaded.
    2. SmartScreen 提示「Windows 已保护你的电脑」时，点「更多信息 → 仍要运行」。部分杀毒软件会把监听键盘的程序当成可疑程序；本程序只做计数。 If SmartScreen says “Windows protected your PC”, click More info → Run anyway. Some antivirus tools flag anything that listens to the keyboard; this app only counts.

    Linux (X11)

    1. 用 AppImage（支持自动更新）或 deb 包。 Use the AppImage (it self-updates) or the .deb.
    2. 只支持 X11：Wayland 不允许程序监听全局输入。透明窗口需要合成器，托盘菜单需要 AppIndicator。 X11 only — Wayland does not let apps listen to global input. A compositor for the transparent window, and an AppIndicator for the tray menu.

    macOS 上也可以绕开这一步，在终端里运行： On macOS you can skip that step instead by running, in a terminal: 

    xattr -dr com.apple.quarantine /Applications/Jokbet.app

    更新后如果不计数了，在「输入监控」里删掉旧条目再重新添加。 If counting stops after an update, remove the old entry from Input Monitoring and add the app again.

    隐私Privacy

    只保存计数：每个键按了几次、点击、滚动手势和鼠标移动距离。不记录输入内容，也不记录按键顺序。所有数据只存在本机，不上传。 Only counts are stored: how many times each key was pressed, clicks, scroll gestures, and how far the mouse moved. It never records what you type or the order of your keys. Everything stays on your machine.

    数据在 ~/Library/Application Support/io.github.sparkjokerben.jokbet/（Windows 在 %APPDATA% 下，Linux 在 ~/.local/share/ 下）。 It lives in ~/Library/Application Support/io.github.sparkjokerben.jokbet/ (the same folder under %APPDATA% on Windows and ~/.local/share/ on Linux).

    这一页上的桌宠也一样：它只数你在这个页面里的操作，用来演示，什么都不发送。 The pet on this page works the same way: it counts what you do here as a demonstration, and sends nothing.

    已知限制Known limits

    • macOS：开了「安全键盘输入」时（终端设置或密码框里），按键对所有程序都不可见，它会戴上眼罩。 macOS: while Secure Keyboard Entry is on (a Terminal setting, or any password field), no app can see the keys — it puts on a blindfold.
    • macOS：没给「输入监控」权限时，它一脸问号，什么也数不到。 macOS: without Input Monitoring permission it is baffled and cannot count a thing.
    • Windows：管理员权限窗口里的输入看不到（除非它也以管理员运行）；它会留在启动时的那个虚拟桌面。 Windows: input going to administrator windows is not seen unless it runs as administrator too, and it stays on the virtual desktop it started on.
    • Linux：只支持 X11，Wayland 下无法工作。 Linux: X11 only; it cannot work under Wayland.
    • 它会待在别的窗口上面，包括全屏应用；挡事的时候从托盘菜单里先隐藏。 It stays above other windows, fullscreen apps included; hide it from the tray menu when it gets in the way.
