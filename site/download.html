下载 Download

推荐用一行命令安装，脚本会核对校验值；也可以直接下载安装包。 One line in a shell is the recommended way in — it checks the checksum for you — or take an installer directly.

安装Install

下面任意一行都可以，这就是推荐的安装方式：脚本会读最新版本、核对 SHA-256，装好并打开。再运行一次同一行，就是更新到最新版。 Any line below does the same, and this is how the project wants it installed: it reads the newest release, checks its SHA-256, installs it and opens it. Run the same line again any time to update.

macOS · Linux（bash / zsh） macOS · Linux (bash / zsh) 

curl -fsSL https://jokbet.jokerben.top/install.sh | sh

Mac 上装进「应用程序」，Linux 上装成 ~/.local/bin/jokbet（AppImage，会自己更新）。从终端安装不带隔离标记，macOS 不会拦；脚本可以先读一遍。 On a Mac it goes into Applications; on Linux it becomes ~/.local/bin/jokbet (the AppImage, which updates itself). A terminal download carries no quarantine flag, so macOS does not stop it. You can read the script first.

Windows（PowerShell） Windows (PowerShell) 

irm https://jokbet.jokerben.top/install.ps1 | iex

它下载最新版的安装程序，核对 SHA-256，静默装好并打开。PowerShell 下载的文件不带「来自互联网」标记，通常不会被 SmartScreen 拦；脚本可以先读一遍。 It downloads the newest installer, checks its SHA-256, installs it quietly and opens it. A PowerShell download carries no mark of the web, so SmartScreen usually does not stop it. You can read the script first.

Windows（cmd） Windows (cmd) 

powershell -NoProfile -Command "irm https://jokbet.jokerben.top/install.ps1 | iex"

命令提示符里跑的就是同一条 PowerShell 命令，做的事情和上面完全一样。 The same PowerShell command, for a Command Prompt window; it does exactly what the one above does.

    安装说明Installing these files

    macOS

    1. zip 双击解压，把 Jokbet.app 拖进「应用程序」。Apple 芯片选 aarch64，Intel 选 x64。 Open the zip and move Jokbet.app to Applications. aarch64 for Apple silicon, x64 for Intel.
    2. 第一次打开会被拦一次，到「系统设置 → 隐私与安全性」点「仍要打开」。dmg 在打开磁盘映像时还会先拦一次。 The first launch is stopped once: System Settings → Privacy & Security → Open Anyway. A dmg is stopped once more, when the disk image is opened.
    3. 按提示授予「输入监控」权限。没有它，桌宠会一脸问号，也统计不到任何操作。 Allow Input Monitoring when asked. Without it the pet is confused and counts nothing.

    Windows

    1. 运行下载的安装程序。 Run the installer you downloaded.
    2. SmartScreen 提示「Windows 已保护你的电脑」时，点「更多信息 → 仍要运行」。部分杀毒软件会把监听键盘的程序当成可疑程序；本程序只做计数。 If SmartScreen says “Windows protected your PC”, click More info → Run anyway. Some antivirus tools flag anything that listens to the keyboard; this app only counts.

    Linux (X11)

    1. 用 AppImage（支持自动更新）或 deb 包。 Use the AppImage (it self-updates) or the .deb.
    2. 只支持 X11：Wayland 不允许程序监听全局输入。透明窗口需要合成器，托盘菜单需要 AppIndicator。 X11 only — Wayland does not let apps listen to global input. A compositor for the transparent window, and an AppIndicator for the tray menu.

    更新后如果不计数了，在「输入监控」里删掉旧条目再重新添加。 If counting stops after an update, remove the old entry from Input Monitoring and add the app again.
